# 图表数据与统计口径

此目录只收录本报告所需的回测聚合结果；不含公司分钟行情原始记录、数据库连接信息或完整账户账本。

- `synthetic_summary.csv`：固定种子合成实验的 25 组汇总指标。
- `real_summary.csv`：公司真实一分钟小样本回放的 25 组汇总指标。
- `real_nav_100m.csv`：一亿元场景的日度归一化净值与现金比例。
- `real_diagnostics.csv`：订单观察窗口、完成比例、两种计时口径及持仓阶段现金比例。
- `real_completed_order_clocks.csv`：完成订单的匿名计时统计，供复算分位数。
- `order_example_cumulative.csv`：一个买单按参与率分组的累计完成比例，用于说明跨日余单。

收益率、完成率与现金比例均用小数存储，图中转换为百分比；资本和费用单位为元。

金额完成率 = Σ(已成交数量 × 下单时参考价) / Σ(下单数量 × 下单时参考价)。它衡量需求完成程度，不等于成交现金额与计划现金额之比。

充分观察订单：已经激活，且执行截止交易日不晚于样本最后一个交易日（索引 45）。本次真实回放中，这些订单全部完成。观察期不足订单：本次均在 2026-09-04 15:00 才产生，未被激活，未成交原因为 `sample_end`。它们需要单独统计，不能被解释为已经受到成交量约束。

自然时间：从订单提交到最后一笔成交，单位小时；保留周末、午休和夜间。模型可执行分钟：从激活到完成，累计计数该股票满足 `activated_at < bar_end <= last_fill_at` 的实际一分钟回放 bar；开盘竞价已在数据预处理中移除，`auction_excluded` 标记的收盘竞价时段也不计入。没有成交的合格 bar 仍计入。该口径描述模型中的交易时间，不能代替真实交易队列中的等待时间。

现金比例均值分别保留日末记录口径（`*_daily_cash_ratio_mean`）与每根回放 bar 后净值记录口径（`*_bar_cash_ratio_mean`），再各自分为全样本与持仓阶段两项；持仓阶段从 2026-08-03 首次执行日开始。图 02 使用每根 bar 后记录的均值。全样本中的前 21 个交易日为因子预热，全现金状态会显著提高全样本均值。

收益差的单位 bp（基点）：（受参与率约束的净收益率 − 同资金不受参与率约束的净收益率）× 10,000。正值在本次负收益样本中表示亏损较少，不能直接解释为执行更优或策略具有正收益。

提取命令接受本地原始产物目录参数；这些路径不会写入 CSV。`make_figures.py` 只读取本目录，可离线重画全部图表。提取脚本含针对本次真实回放观察窗口和三个一亿元计时结果的断言，以避免把截断需求或自然时间错画成容量结论。
