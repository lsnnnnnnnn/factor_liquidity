# 因子流动性报告

本bundle由真实保存的账户与严格验收表生成。若metadata标synthetic，则仅为合成测试样例。

编译：在本目录执行 `xelatex -interaction=nonstopmode -halt-on-error main.tex` 两次。

图表数据位于data/，证券级完整计划和瓶颈表位于运行输出的private/，未放入公开bundle。未完成窗口不填全期收益；未验收资金不算通过。

special_cases_summary.csv按每个账户的原日独立计划统计证据标签，不累计次日重试和重复约束事件。标签可重叠，不能相加或解释为未成交的唯一原因；停牌事件、持续时段未知及停牌状态未知分别记录。封板观察仅覆盖所保存的证据时点，不等于全天封板。特殊情况不豁免全部计划100%主判据。证券级special_cases.csv/parquet留在私有目录。

run_progress.csv来自已保存的搜索与账户状态，显示当前资金档和已完成日期；生成报告不等于重新确认进程在线。

completion_time_summary.csv以原日正数量计划为分母，扣午休，保留未完成与时间未知；耗时分位数仅描述已完成计划，不代表全体平均。
intraday_cases.csv只含所选匿名案例的真实观测与成交轨迹；对应私有资料保留在private/。
额外冲击是参数情景的独立现金成本；盘口与扫板价格成本已在成交金额中，不可再次从净值扣除。不同连续账户路径的收益差不等同于直接冲击费。没有收益或可接受成本阈值，不定义经济容量。
