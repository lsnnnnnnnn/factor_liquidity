# 因子流动性容量工具

输入逐日逐证券因子值、原始分组或已核实的目标目录，以及组合和执行配置，工具自动运行流动性容量测试，生成中文 PDF、可编译 LaTeX bundle 和图源汇总表。实际数值以各发布目录中的 `data/report_metadata.json`、`data/trial_summary.csv` 和报告为准。

本目录用于发布新的通用工具报告。原 `l2_tex_bundle/` 中的正文和用户编辑保留在原处。新报告不覆盖这些文件。

已发布的 v3 代表结果：[中文 PDF](representative_v3/main.pdf) · [可编辑正文](representative_v3/main.tex) · [LaTeX bundle](representative_v3_tex_bundle.zip) · [规则与结果元数据](representative_v3/data/report_metadata.json)。真实 N20、1,000万元的四个连续账户均完成162个交易日并通过独立核账，均未达到全部原计划当日100%。这一单资金代表结果不用于推断其他资金档或五 N 的最终容量。

|---|---:|---:|---:|
| 常规 | −8.64904% | 未启用 | 1,047 |

冲击参数为下文定义的5基点假设，未用真实订单校准。额外成本已在成交前进入现金与可成交数量，后续持仓路径也有变化，因此两账户收益差不等于直接冲击费用。报告含原计划30／60交易分钟表现，以及正常完成、实际扫板和部分成交的三个匿名日内案例。

## 实验设置

验证因子为 F000001 的真实 N20、N61、N121、N241、N481；各 N 使用自己的原分组，沿用 G1 等权、H20 原调仓相位、历史股票池与资格规则。窗口为 2024-01-02 至 2024-08-30，共162个交易日。使用前一交易日信号，09:35形成目标，一次现金投入、零初始股票，不融资，账户连续保留现金、持仓、可卖状态和权益。

资金粗档为1,000万、3,000万、1亿、3亿、10亿、30亿、100亿元。通过条件始终为**全部原计划在原日100%完成**；次日补成不能改写原日结果，正数量尾单不能事后删除。资料不足保留待判定。容量只表示本窗口和指定情景的最大已测通过资金，不能把未测区间插值为通过，也不能把没有通过档写成市场容量为零。

常规情景同时受有效新增成交量10%及截至当时已知累计成交额10%的限制。同股订单共享额度，所有买单共享现金。执行窗口为 `[09:35,11:30)`、`[13:00,14:57)`，正报单延迟为1毫秒，随后在合格快照执行。

对称1个百分点扫板是独立基线：10%制度在上涨9%／下跌9%时触发相应买／卖方向，20%制度对应19%。触发后实际观察到的有效新增量按100%提供共享额度，买按官方涨停价、卖按官方跌停价；不倒用触发前成交量。现金、可卖和数量规则仍生效。这一情景假设不等于真实排队成交保证。

## 参考价与额外冲击

采用 `event_state_same_am_v1` 的新账户，使用决策前已经读取的 `[09:34,09:35)` 窗口内的当日早盘观测。正常静默超过30秒本身不使参考价失效；最新观测无效时不退回更早有效报价，已知复牌后仍需新的合格观测。窗口内无参考观测不等于当日无行情。每份报告保存实际 `rule_version` 和 `reference_price_rule`；旧账户的 `max_age` 规则仍单独说明，重新出报告不改变它的金融计算。

常规盘口成交已经包含价差和可见跨档成本。新增 `incremental_sqrt_turnover` 模型估计其外的独立经济成本，使用同账户、证券、方向、交易日的累计执行金额和当时已知市场累计成交额，成交前联动现金预留、可负担数量与卖出净收入。子单拆分不会清空累计状态，独立核账重算成本和现金。

`bps_at_10pct` 为可配置参数：在固定市场量下，累计执行额占该量10%时对应的累计平均额外成本基点数。它是敏感性参数，尚无公司真实母单／子单记录进行实证校准；实际取值写入每份报告。原常规与扫板基线保留，新冲击情景分别命名为 `regular_impact`、`sweep_impact`。

经济成本独立进入现金，官方成交价保持合法，不以越过涨跌停或截价后保证全成表示冲击。历史扫板100%新增量可得仍是既定假设；成本模型没有复原其他交易者反应。只对旧路径事后扣成本的结果必须标为固定路径敏感性，不能称为新成交容量。没有最低收益或可接受成本阈值，因此不另设经济容量线。

## 阅读和复现

发布目录中的 `main.pdf` 为阅读版，`main.tex`、`figures/` 和 `data/` 构成可编辑报告。每个发布目录旁另附同名 LaTeX ZIP。在报告目录使用 XeLaTeX 编译两次，或在 Overleaf 上传 bundle 并选择 XeLaTeX：

```bash
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

完整工具位于公司代码仓库，统一入口为 `factor-liquidity prepare/run/report/status/demo`。已安装且配置好私有输入和行情时：

```bash
factor-liquidity prepare --config configs/my-factor.yaml
factor-liquidity run --config configs/my-factor.yaml
factor-liquidity report --study /path/to/study --output /path/to/new-report --refresh-evidence
```

`report` 汇总保存账户，不重新回测；默认可复用已保存的报告快照。`--refresh-evidence` 重新读取账户诊断，用于新增或更新的保存结果。公开文件不含运行私有真实账户所需的原始输入与账本。

代表账户与完整五 N 资金搜索分别发布、分别标明实测范围。完整研究保持五 N、四情景、1,000万至100亿元的七个粗档；全部完成并核账后单独发布。旧49档只作为历史基线，保留原参考价规则和结果时点，不作为新参考价、新冲击模型的容量结果。
