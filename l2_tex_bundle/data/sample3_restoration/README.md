# 实际共享sample3恢复与独立账户重建

共享五张宽表已实际读取。这里仅保留派生统计、日级核账差额和沿用价账面占比，不含原始价格矩阵、证券级计划/成交/持仓、完整账户或私有配置。

- `restoration_review.json`：139409行成交、249358行持仓、256个快照按原字段和证券位置核对；原dtype元信息保留，pandas3默认把object字符串读为str的区别单列。
- `account_validation.json`：1355日独立根据实际金额/复权成交价递推持仓，再估值；原交易units只用于核对。固定实际成交路径的零费NAV已重建，不是重新按零费目标定量的策略或原始股数账户。
- `daily_validation.csv`：全部日级NAV差额、沿用持仓数和沿用账面金额占比；无证券身份及逐股数量。
- `boundary_accounts_summary.csv`：4个归一化复权账户边界汇总，不是原始股数、可卖量或全账户导出。
- `price_comparison.json`：原始开盘价与已有服务器日线相同，但复权因子批次数值不同，不自动替换或归一化；实际行情交集不能当完整持仓覆盖。
- `boundary_market_review.json`：01-10的14个沿用价持仓在当前生命周期参考中均有早于2024的退市日期且当日日线零行；这不能给出退市资产清算/补偿价值，没有将其清零。
- `test_results.json`：本轮294项测试通过。

正常数值比较和价格/账户等式用于核对；ZIP仅作普通读取和打包，未发起额外哈希、校验和或指纹验证流程。数值精度检查不等于容量或数据业务合格线。
