# 10 月 21 日新增派生表

这里只放执行规则对照所需的派生结果；不包含私人因子成交明细、原始 L2、完整账户或服务器配置。原 `data/` 表与原正文保留为 10 月 19 日历史结果。

- `fixed_rule_groups.csv`：固定旧 22 笔母单，六种规则×原14大单/7尾差/1停牌三类，共18行。`remaining_reference_notional` 单位元，是历史未成需求的参考金额合计，不是收益损失或期末挂单。每个变体维持 10% 参与率，单变量改变累计、盘口刷新、余单保留或卖出余股；`main` 组合这四项。
- `residual_reason_summary.csv`：同一22单在每种规则下的具体剩余原因、笔数、股数和参考金额。正常市场障碍、已设限额不足、数量规则/历史尾差和待查分别保留，未成不退出分母。
- `hand_examples.csv`：000529/000550在08-03及000530在08-24的三个手算例，六种规则共18行。市场全日股数/金额、有效窗口、排除量、取整前/后额度和新实际成交均保留。全日量只作事后核对，不反过来决定先前下单。
- `continuous_summary.csv`：旧1亿元10%路径及新参考假设、10%、不限参与率三条连续路径的派生汇总。费用全部零；全期收益为百分数，`return_diff_pp` 是相对参考假设的百分点差，不是相对原回测的正式流动性差。`final_nav` 单位元。新三路径均从同一初始账户完整重跑26日。
- `daily_nav_comparison.csv`：26个观察交易日的旧10%、新10%和参考假设净值，均以唯一初始现金为1。没有删除中间日期或每周重置。
