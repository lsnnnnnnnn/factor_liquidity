# 本轮公开派生统计

本批次为2024-01-02—08-30的162交易日连续账户：五档资金×五种成交情景，共25账户，8次新目标。各账户分别从指定初始现金、零持仓起步，费用及税费为零，不融资。数据仅为账户与原因分类的汇总，不含证券身份、逐证券目标、原始L2或完整流水。

| 文件 | 数据行数（不含表头） | 内容 |
|---|---:|---|
| `daily_nav.csv` | 4,050 | 25账户×162日：现金、市值、权益应收、净资产、净值及回撤 |
| `window_summary.csv` | 75 | 25账户×3个观察末日：03-14、04-15、08-30 |
| `account_comparison.csv` | 75 | 上述窗口与同资金、同末日参考账户的对照 |
| `new_target_progress.csv` | 200 | 25账户×8个新目标日的固定计划进度 |
| `data_exposure_daily.csv` | 4,050 | 每日缺参考、权益限制、数量限制、估值及应收暴露 |
| `unfilled_reasons.csv` | 14,684 | 按日期、情景、原因和金额口径聚合的未完成或未定量记录 |
| `research_metadata.json` | — | 因子版本、时序、费用、融资及215只共同限制设置 |

75行窗口表是同一次连续运行在不同末日的观察结果，均已完成；不是在各窗口重新投入现金。报告主图使用08-30完整窗口的25行结果。

## 指标口径

金额单位为人民币元，收益和最大回撤为百分数，收益差为百分点；`completion_*`、`*_fraction`及目标权重为0—1比例。各账户与自己的同资金参考账户比较，不混用其他资金或不同日期的结果。

净值为日末净资产除以唯一初始资金。回撤从含初始现金的历史最高净值计算。参考账户也受现金、数量、T+1、权益、延迟和共同数据资格约束，仅不设盘口数量及参与率上限。

计划完成率用父计划参考价将已成交及计划数量换成金额，再汇总相除。主完成率只统计每次新目标日已固定的父计划，次日重试不重复计作新目标；无分母时留空。缺参考而无法定量的目标保留原权重，单独记录，不挤进已定量计划分母。

`new_target_progress.csv`的30／60分钟为交易分钟，不含午休。`window_summary.csv`的完成耗时仅统计明确完成的任务，未完成者另列数量和金额。滑点仅计算实际模拟成交部分；未成交部分没有虚构价格或完成时间。

`first_positive_integer_target_count`是首日取整后正数量目标数，`first_actual_positive_holding_count`是首日日末实际持有数，`first_cash_nav_fraction`是首日日末现金占净资产。正数量不一定满足所有申报要求，也不一定成交。小资金可能因此持仓较少、现金较多，不能只凭收益或完成率解释流动性。

`unfilled_reasons.csv`的两类scope分开使用：`daily_parent_attempt_unfilled`金额为剩余数量×父计划参考价；`daily_unquantified_target_exposure`金额为冻结净资产×原目标权重。两者不能拼成一个完成率分母。图4只取1亿元10%路径的8个新目标日固定计划，不累加其他重试日或未定量暴露；剩余金额也不是窗口末仍挂单的金额。参与率额度不足以满足申报下限归“参与率额度”，不与普通数量单位限制混淆。

每日暴露不能跨日相加当作新增需求。日末才确认的整日缺L2、状态未知等记录仅供事后解释，不作为早晨已知输入。股与份的数量分列，不直接混加。

## 本批次数据条件

215只证券因关键权益分配资料不足采用共同限制，原目标权重保留、不向其他证券重新分配。源库原581个整日零L2证券日已补出记录，本轮尚未用新记录替换已保存缓存。数据对应这一批次，不表示源库仍然缺少这些记录。

2024年参与过原参数选择，本研究不称为独立样本外；未确定业务收益要求，不提供资金容量上限。公开汇总可重画图表、编译报告，不能单独用于重跑私有L2账户。
