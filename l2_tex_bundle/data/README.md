# 精简图源与指标口径

这里只保存派生统计和可控手算。公司原始 L2、完整逐笔账户、私有配置、连接信息和凭据不进入本目录。除 `handcalc_levels.csv` 的明示可控例，其余结果均来自实际运行，不用合成数字填补真实缺口。

- `summary.csv`：5 档资金的原参考、L2 不限参与率、L2 5%/10%/20% 共 25 个主情景，以及 3 个延迟/刷新敏感性情景。`is_base=1` 为主实验。
- `order_metrics.csv`：图中所需逐单目标量、成交量、余量、完成用时和有符号滑点；`lifecycle_reason` 保存当日终止状态，`last_constraint` 保存最后有效约束，`constraint_counts_json` 保留全过程非互斥约束计数；不是完整账户。
- `nav.csv`：各情景同一估值日的归一化净值；为净资产除初始资金。
- `handcalc_levels.csv`：独立买卖可控盘口的档位、价格、可见量和实际取用量。
- `data_quality.csv`：每股票日的覆盖与量额核对统计，不包含快照序列。
- `phase_summary.csv`：逐股票日的连续竞价、竞价及午休等阶段聚合量额与行数。
- `daily_warmup.csv`：官方日历对照的两股 21 个预热交易日，08-31 至 09-29 均无缺日。
- `study_metadata.json`：实际采用的调仓、计费、延迟、刷新及检查说明。

`completion_30`、`completion_60`、`completion_day` 用 0..1，图和报告换算为百分比。分母是母单目标股数乘下单参考价的总和，买卖绝对金额加总；分子是该观察时点已成交股数乘同一参考价。未成交需求不从分母删除。

`return_pct` 是百分数，`return_diff_pp` 是相对同资金原参考执行的百分点差；不是基点。净资产包含现金、持仓市值和应收，再扣融资负债；借还本金不改变净资产，利率为 0 是明确的工程情景。

`completion_trading_minutes` 只对全部完成的母单填写，未完成保持空值，图中另列笔数。正常交易时段中缺报价仍消耗等待时间，午休、隔夜和竞价排除。`slippage_bps` 的买卖符号统一为正值不利，按实际成交数量加权；未成交量不虚设成交价。

信号在 2026-09-30 盘前读取已归档截至 09-29 的 21 个官方日收盘，而非声称 09-29 收盘即时可得；日线字典为 D+1 06:10 后可知。参考价为前一收盘反事实，隔夜暴露保留在滑点。用户补充确认量、额及累计字段口径、2025-02-17 至 2026-10-15 边界和日更华鑫压缩包来源，这不构成本轮全区间认证。

`participation` 是相对前一有效快照区间量的下单额度，不是当前实际区间占比。`volume_source_time` 等精细时序和逐档消耗留在本地审计输出；公开图源足够复算报告，不代替账户证据。

`data_quality.csv` 的公开核验以每股票日排序后相邻累计差与原区间增量严格比较，跳过各日第一行；日终累计与官方日线严格比较。执行器的额度资格另排除跨日、跨阶段和超过 10 秒的未知间隔，数量累计误差容忍为 1e-8 股，金额为 0.02 元。连续竞价采用 [09:30,11:30)、[13:00,14:57)，其余阶段只保留和核验，不用来成交。所有 6 股票日均未发现连续竞价的零价零量档、盘口逆序、交叉盘或饱和值；竞价的零档记录仍保留。

22,798 行里 000001.SZ 在 10-08 有 7 条、10-09 有 1 条原区间量额为 0 而累计变化。日终累计与官方日线全部相等，但两日的区间量额合计分别比官方少 149,700 股/1,770,003 元和 1,100 股/12,848 元。000529.SZ 的 >10 秒连续竞价间隔三日分别有 311、287、280 次，最大 54、66、48 秒；这说明更新不规则，不能直接称作无成交能力。本目录不新增哈希或校验和检查。

价格诊断仅是描述性统计：`cross_depth_bps` 为成交价相对执行快照最优对手价的买卖同号成本，`latency_best_quote_bps` 为源快照到执行快照最优对手价的同号变化，`observed_spread_bps` 为执行快照完整买卖价差相对中价。三者均按实际成交金额加权，`diagnostic_filled_notional_coverage` 记录可计算覆盖比例；本轮实际 L2 成交覆盖均约 100%。这些诊断不能相加当作永久冲击分解。组合 `mean_slippage_bps` 使用已成交参考金额加权，与诊断金额权重不同。

图 05 的计数仅取 1 亿元、10% 主情景的未完成买单，排除 `source_outside_continuous`、`source_session_boundary`、`source_day_reset`、`source_no_preceding_snapshot` 等阶段边界；将 `source_unexplained_gap` 与 `arrival_gap_or_session_boundary` 合并显示为未知长间隔/到达跨界。图计数是事件记录次数，可能同一执行步多因；不代表剩余股份的互斥原因分配。本例额度约束 378 次、额度取整为零 1,694 次、未知长间隔 311 次、到达跨界/缺口 15 次。
