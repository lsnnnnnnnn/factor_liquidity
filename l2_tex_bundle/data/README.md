# 公开派生数据与指标口径

这里只保存本次扩样研究的派生表，来自实际执行输出。两股 L2 小样随 `v2` 保存，旧分钟实验随 `v1` 保存；不与本版 CSV 混用。原始盘口、完整账户和连接信息不公开。

- `summary.csv`：每实际事件、资金和执行模型一行。三个完成率为 0..1，`return_pct` 为独立当日净收益百分数，`return_diff_pp` 为相对同事件、同资金原参考执行的百分点差。
- `order_metrics.csv`：每场景母单的冻结目标、实际成交、余量、参考价、完成率、完成用时、滑点、生命周期及累计约束记录，并带事件日期、预热流动性层和方向。不代表完整账户。
- `group_summary.csv`：跨事件、按资金和模型的需求金额加权完成率及事件描述性分位数。事件收益没有复利。
- `stratum_summary.csv`：按预热流动性层和买卖方向分组的需求金额加权完成率与已成交滑点。
- `events.csv`：实际可评估事件中每股的排名、动量、参考价及来源、停牌和陈旧价标记。
- `warmup.csv`：实际信号的 21 个官方预热交易日日期与停牌缺日填值证据，不含逐日价格；带收盘价的完整信号预热表保留在授权本地。
- `selected_pool.csv`：研究前按 2026 年 3 月预热成交额选定的高、中、低各 10 股；仅深圳 000 代码子集。
- `data_quality.csv`：全部 420 个计划股票日的覆盖、相邻区间/累计量额核对、日终/日线核对、长间隔和盘口质量，含零行。`date` 为计划日期，`symbol` 为证券，`rows` 为实际查询行数。
- `phase_summary.csv`、`source_quality_reasons.csv`：股票日的交易阶段聚合与额度来源无效原因；同一行可有多个无效原因。
- `daily_warmup.csv`、`validation_summary.json`：独立质量核验的预热覆盖与汇总，不替代实际信号的 `warmup.csv`。
- `event_eligibility.csv`：计划事件可评估性与缺失、停牌证据说明；未知整日缺行情不作为零成交结果。
- `coverage.csv`：计划 420 个股票日的原始查询计数与覆盖证据，包含 07-01 的零行；不含原始快照序列。
- `closing_state.csv`：420 个计划股票日的事后末段方向限价及零对手盘诊断，不含原始最新价或盘口数量。须按日期、证券、方向关联实际未完成需求，不能将全部市场标记都算作本策略未成单。
- `market_environment_suspensions.csv`：历史停牌环境与其记录时点；用于阻止陈旧盘口的虚假成交，不宣称当时策略已知。
- `handcalc_levels.csv`：本轮可控买卖手算的逐档取量，属于明确的工程例子。
- `study_metadata.json`：实际研究范围、初始化、费用、时序、深度、融资、数量规则及解释边界。

`event_date + scenario` 才是场景唯一键，不能仅按 `scenario` 合并不同事件。母单目标参考金额等于 `target_qty * reference_price`；买卖都取正值，未成交需求保留。三个时点的分子为对应已成交股数乘同一参考价。跨事件先汇总分子分母，不直接平均股票完成比例。

完成用时仅对全部完成母单填写，未完成留空。交易时间排除午休、竞价和隔夜，正常交易时段内缺报价仍消耗等待。滑点只对实际成交部分计算，买为 `(成交均价-参考价)/参考价*10000`，卖为反号；正值不利，1 bp=0.01%。未成交需求没有虚设成交价。

每个事件使用独立初始账户和相同当日估值终点，净资产为现金+持仓市值+应收-融资负债，费用已扣除。借还本金不产生收益；零融资利率仅为工程设置。事件收益差、中位数、分位数不构成三个月累计收益，重复股票和场景也不增加独立样本数。

`volume/turnover` 是相邻入库快照的增量，`acc_*` 只作核对；参与率是相对前一有效区间的下单额度，并非当前区间实际成交占比。快照按裸北京时间解释，真实纳秒时间保留。长间隔阈值为 10 秒，连续竞价使用 [09:30,11:30)、[13:00,14:57)。失配和未知间隔不得伪装为没有市场成交。

约束计数来自未完成母单全程的 `constraint_counts_json`，同一执行步可同时存在多个原因，次数不分摊全部剩余股份。已剔除非连续阶段边界等常规记录；未知间隔、可见深度、参与率、取整、停牌证据等分别说明。盘口历史作为外生环境，不能由这些诊断识别自身永久冲击。

`closing_directional_limit_no_depth` 与 `closing_quote_fresh` 只作事后诊断：官方方向限价、有效末段连续盘口在 14:57 前 10 秒内、相应原始对手盘全无。1 亿元、10% 且实际未完成的母单中，买单 2 笔、卖单 1 笔满足；不证明全天封板，不修改已运行的生命周期，不代表已模拟跨事件延续。
