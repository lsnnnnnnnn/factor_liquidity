# 连续报告的数据与计算方法

这些表来自 2026-07-31 至 09-04 的连续账户。每档资金、每种成交方法只初始化一次，包含全部 26 个交易日和 5 次调仓。当前版本的交易费、税费、最低费和借款利息都为零，不主动预留现金；不与旧计费结果或每个日期重新开始的表混用。原始 L2、逐日收盘价和完整账户流水不公开。

## 文件

- `summary.csv`：每个连续账户一行。`total_return_pct` 是全期收益百分数，本版不扣费用；`total_fees` 必须为零。`max_drawdown_pct` 是全期最大回撤的正数百分比，`return_diff_pp` 是全期收益减去同资金参考账户收益，单位为百分点。三个完成率为 0..1，按五次各自实际需求金额合计。
- `daily_nav.csv`：每天实际净资产、净值、当日收益、累计收益和回撤。`scenario + trade_date` 唯一；没有调仓的日期也保留。
- `signals.csv`：五次调仓的排名、20 日动量、目标权重、已知参考价及时间来源。只用此前收盘价排名，没有发布逐日价格序列。
- `selected_pool.csv`：按 2026 年 3 月成交额排名分成三组、各等间距选出的 10 只股票，研究期间不换池；这是预先确定的深圳 000 子集，不是全 A 股随机抽样。
- `target_history.csv`：各组形成目标时的净资产、实际持股、应收股份、经济持股、目标股数与净买卖股数。相同信号下的目标权重相同，目标股数可因各自净资产和真实持仓而不同。
- `order_metrics.csv`：每笔实际买卖任务的股数、参考价、成交、剩余、30/60 分钟与当日完成率、成交价差及结束原因；费用字段全部为零，不是逐笔成交或完整账户流水。`scenario + order_id` 唯一。
- `rebalance_metrics.csv`：每个账户每次调仓一行，记录形成目标时的净资产、全部买卖需求、分买卖完成率、当天未完成笔数，以及收盘持仓距本次目标的差距。
- `corporate_action_summary.csv`：各账户对已知行动的登记股数、应收和实收金额/股份、日期与期末应收余额；零持股事件也保留。
- `input_quality.json`：本窗口的输入预检结果；逐日执行中的活跃续单行情还须在回放时核对。
- `study_metadata.json`：窗口、账户和选股规则、原季度未完成原因、实际行情数量、补充续单行情、陈旧估值、权益证据范围、代码版本与验证情况。

## 连续收益和回撤

净资产 = 现金 + 股票市值 + 应收权益 - 借款，不扣任何费用。`normalized_nav = nav / initial_capital`；`cumulative_return = nav / initial_capital - 1`；当日收益用当日净资产除以前一天净资产再减 1，第一天以前述初始资金作分母。

回撤用当天净资产除以此前最高净资产再减 1，历史最高值也包含最初现金。`drawdown` 通常小于等于零，`max_drawdown_pct` 把最深下跌换成正数百分比。这里直接读取一条连续账户路径，不拼接旧版独立单日收益。

## 各次完成了多少

计划金额为 `quantity * reference_price`；已成交部分也乘同一参考价。买入和卖出都按正金额相加，不互相抵消。未成交部分保留在分母，多个日期先加总金额再相除。

各账户每次根据自己的净资产和实际持股重算，所以它们的后续需求不同。各自完成率的分母都是真实完整需求，不能称为同一份固定股数订单的完成率。首次全现金开仓没有卖单，卖出完成率留空，不能填成 0% 或 100%。

`completion_eod` 只看提出订单的当天。`incomplete_eod_orders` 数当日没全部做完的任务；`ever_carried_orders` 数曾跨日的任务；`open_at_end_orders` 才是研究结束仍有效的任务。`incomplete_orders` 统计所有历史母单最后仍有残余的笔数，包含已到期或取消的任务，不能叫期末未完成活单。

## 收盘时离目标还有多远

逐股用本次目标股数减收盘经济持股（实持加已生效应收股）。正数是还没买到，负数是还没卖掉；分别乘本次参考价。两边绝对金额相加得 `position_gap_reference_notional`，除以形成目标时的净资产为 `position_gap_pct_nav`。单位是百分数，和完成率的 0..1 不同。

这项计算看股数未到位，不把收盘价格变化当作没成交。差额按各股票分别计算，不能用一只股票多买的部分抵消另一只少买的部分。

## 行情和权益的边界

L2 的区间量额限制下一笔发出数量，累计量额用于核对。下单经过正的延迟后，只能用更晚的十档对手盘口成交；不把区间均价当作可无限成交的价格。模拟用过的同价位数量在当天继续扣除。

日线缺失仅在有明确停牌证据时沿用此前价格；有活跃跨日订单却缺 L2、又没有停牌证据时停止运行。未知缺数据不是零流动性。公司行动源声明为公告窗口，只对所提供的市场公开版本和生命周期做核对，不扩大为所有经济事件完整性的认证。

现金分红按登记时真实持股全额确认，应收生效与付款分别记录；付款只是应收转现金，不能重复增加收益。税费、临时融资利息均为零，也不预留现金，负债始终从净资产中扣除。收益差同时包含持仓路径、价格和后续需求变化，不是纯粹的市场冲击估计。
