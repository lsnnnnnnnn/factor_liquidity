这里只发布派生汇总，不包含私人因子包、证券级交易/持仓、完整账户、原始行情或连接配置。

- `amount_checks.json`：实际139409行成交与日账、尝试汇总的金额、费用和连续现金等式核对。仅归一化金额账，不是原始股数或独立估值。
- `candidate_windows.csv`：按时间最早的两次／三次new_target与后续持有期，未按收益挑窗。证券数仅指已成交证券，不能当完整目标或持仓集合。
- `monthly_market_checks.csv`：2024实际成交涉及的20414个证券日期的整日聚合。L2存在不等于盘中连续、可执行或通过质量验收。各差异列可以重叠。
- `coverage_summary.json`：10月22日通过既有只读接口取得的范围与限制。日线同属L2派生链，不能当完全独立源；其复权字段可读也不证明与原包共享批次一致。
- `auxiliary_summary.json`：日历、涨跌停、正面状态、候选公司行动和范围说明。稀疏视图缺行不证明正常，单个CDR公告覆盖也不是全月或全期覆盖。
- `source_quality_cases.csv`：两个实际10行片段按当前快照价格界核查的行数结果，未输出原始证券字段，没有生成母单或成交。

金额差1元、收盘价差0.005元只用于列出核查记录，不是容量、成交完成率或数据合格阈值。负增量原值保留，没有自动乘十、补量或改写成交金额。缺L2的4个证券日期没有被删除。
