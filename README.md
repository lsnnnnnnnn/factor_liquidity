# 连续账户的因子交易实验

**10 月 21 日新增附录：**执行器已增加已知额度累计、有效子单余量保留、深市样本余股处理和原始/模型盘口原因区分；固定原 22 单做了 132 次单变量回放及 44 项同时推进检查。原 10 月 19 日正文和 25 路径结果保留，新增比较情景与旧规则分开。新版 14 笔较大单仍全部未完成，不能把参数限额不足都称为 bug。真实新 H20 包属于 2007—2009 年 sample1，且缺共享价格、真实股数、逐证券母单及匹配 L2；正式因子收益差未算出。详见报告附录及[新增图源](l2_tex_bundle/data/execution_update/README.md)。

这次看一个账户连续运行时，**买不够、卖不完会怎样影响之后的持仓、调仓和收益**。账户只在第一天设置一次，现金、股票、借款和权益逐日保留；没有调仓的日期也计算净资产。

本轮完全不考虑费用：买卖交易费、税费、最低费和借款利息全部为零，不主动预留现金。各账户按这套设置从头运行，结果不是把旧收益简单加回手续费。

本阶段使用原来选好的 30 只深圳 000 代码股票，观察 **2026-07-31 至 2026-09-04 的 26 个交易日**。7 月 31 日只有现金，保留当天的权益登记状态；8 月 3 日首次买入，此后在 8 月 10、17、24、31 日调仓，共 5 次。选股暂用此前 20 日未复权价格涨幅，把净资产等额配置到排名前 15 只，尚未接入公司的正式因子。

每档初始资金分别运行五种成交方法：假设按参考价全部成交；使用真实 L2 盘口但不限参与率；参与率为 5%、10%、20%。大家使用同样的选股排名和目标权重，但每次按自己的净资产和实际持仓计算需要买卖多少。前次少买或少卖会影响后面的需求，因此未来订单股数不要求相同。

原 7 月 1 日至 9 月 30 日的季度窗口仍因数据不足而没有完成：7 月 1、2 日全池缺 L2，7 月公司行动证据也不完整。没有删除中间日期后冒充完整季度结果；本报告只解释上述连续五周的结果。

25 个账户共保留 650 条日终估值、3,750 条调仓目标和 2,255 笔买卖任务，全部通过账户核对；158 项引擎测试通过。1 亿元、10% 参与率的全期收益为 **-3.24%**，比参考账户低 **1.93 个百分点**，最大回撤 **8.27%**。该组五次实际需求合计的 30/60 分钟和当日完成率为 **63.99% / 72.63% / 87.61%**；研究结束时所有账户都没有仍有效的未完成任务，已经买到、尚未卖出的持仓仍留在账户中。

本窗口读取 154 个股票日、666,839 条 L2 快照，含 4 个非调仓日的续单行情。两条已知分红事件在所有账户登记时均为零持股，所以真实样本没有非零分红入账；非零权益处理另有合成手算测试。6 页报告已用 LuaLaTeX 编译，并逐页查看中文、数字、表格和四组图。

桌面副本在零费用下完整重跑 26 个交易日、100 万元的三个账户，45 张 CSV 和账户核对 JSON 均与正式结果逐字一致。输出位于桌面交付目录的 `outputs/desktop-zero-fee-smoke-20261019`，核对记录在 `review/desktop_reproduction.json`。

此前计费的连续账户结果保留在 [563beed](https://github.com/lsnnnnnnnn/factor_liquidity/tree/563beed) 的 Git 历史中，不与本轮结果混用。

## 查看与重画

已有 TeX Live / MacTeX（ctex、Fandol、latexmk、LuaLaTeX）时：

```bash
git clone --branch main https://github.com/lsnnnnnnnn/factor_liquidity.git
cd factor_liquidity/l2_tex_bundle
make pdf
```

附带的图表可以直接编译，不需要 Python 或数据库。使用 Overleaf 时，上传 ZIP 中 `l2_tex_bundle` 的内容，主文件选择 `main.tex`，编译器选 **LuaLaTeX**。附带 CSV 可以在不连接数据库的情况下重新画图；命令与计算口径见[编译说明](l2_tex_bundle/README.md)。

上一版 13 个单日实验保存在[提交 51a539f](https://github.com/lsnnnnnnnn/factor_liquidity/tree/51a539f)，此前两股 L2 小样在 [`v2`](https://github.com/lsnnnnnnnn/factor_liquidity/tree/v2)，旧分钟实验在 [`v1`](https://github.com/lsnnnnnnnn/factor_liquidity/tree/v1)。原始 L2、完整账户、逐日价格序列、配置和凭据不进入公开仓库。

收益差包含成交价格、等待、未成交持仓和后续调仓变化，不能都说成市场冲击。尚未约定完成率、用时和收益的合格标准，也未覆盖指定的 2024 年压力行情，本次不给出资金容量上限。
